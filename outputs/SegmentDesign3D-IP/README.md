# SegmentDesign3D IP

元のSegmentDesign3Dを残したまま、Instruct-Particulate用の入力フローを確認するWindows向けStreamlitプロジェクトです。
既存の二列レイアウトとPlotlyによるメッシュ表示のコードを基に、必要な部分を別フォルダへ移して作成しました。
元の`C:/Users/mrkab/GH_hops/SegmentDesign3D/SegmentDesign3D`のファイルは変更していません。

現在の範囲は`GLB＋編集要求 → オブジェクト名推定 → パーツリスト・接続方針の生成 → 分割・表示 → パーツごとのスケーリング・移動 → なじませ接続 または 閉鎖・延長・Boolean結合 → GLB／NPZ／STL出力`です。
Rhino・Grasshopper・旧PARTFIELD APIは呼び出しません。倍率を変更したパーツから接続先へ、接続面の法線方向の変位を伝える追従も利用できます。

接続方針の自動設定には、[WSL側の3ファイル更新](../ip-object-name/PREPARATION_API.md)と新しいパーツ構成の生成が必要です。「LLMによる接続方針・変更」で接続ごとの方式を変更でき、閉鎖・延長では基準側も選べます。既存のテキストLLM応答を拡張しており、セグメント後の形状分類や追加API呼び出しはありません。

なじませは編集したパーツ自身に適用します。Cupを編集すればCupに、Handleを編集すればHandleに適用し、両方の編集は合成します。追従で動いただけの接続先は、その移動を保持します。重みは元の接続先の三角形表面までの距離で決め、複数断面でも同じ表面距離を使います。遷移幅はパーツBoxの最長辺に対して初期60%で、距離は一度計算して再利用します。マグで確認する場合は、UIの接続方式を「なじませ」にします。基準側を選ぶ操作は不要です。この変更はWindows側だけで反映されます。

「編集したパーツから接続先へ追従」は、同じ相手への同じ向きの複数断面を共通基準面にまとめて使います。Cupを拡大すればHandleが、Handleを拡大すればCupが動きます。固定した追従の基準パーツを切り替える操作は不要です。複数の倍率変更は合成し、編集順による位置の飛びを防ぎます。「検出した接続関係」で面の法線と残差を確認できます。Windows側のStreamlitを再起動してブラウザを再読み込みすると、新しい追従計算が反映されます。

編集スライダーは、要求文の分析で選ばれた操作だけをパーツごとに表示します。「取っ手を大きくする」ならHandleの一様倍率だけ、「接続面に沿ってずらす」ならU・V移動を表示します。選択されなかったパーツも3D表示と自動追従には含めます。パーツ構成の表に操作と選択理由を表示し、保存したGLB・NPZの編集メタデータにも選択結果を保持します。
3軸の矢印はスライダーの選択と独立して全パーツに表示します（「移動軸を表示」がオンの場合）。移動スライダーは各方向の必要性を個別に判断し、方向不明だけを理由に3軸すべてを選びません。自由な3次元移動を明示した要求では3軸を使用します。

この選択には[WSL側の2ファイル更新](../ip-object-name/PREPARATION_API.md#編集パラメータ選択への更新)が必要です。更新後にStreamlitを再起動して「パーツ構成を作成」からやり直してください。旧結果は全操作を表示する互換モードになります。完全に対応する操作がなくても既存の4種類から最も近い候補を提示し、近似であることと副作用を理由・警告に示します。例えば長さだけの変更は一様倍率で近似し、太さも変化することを明記します。

## 操作

1. GLBを選択する。入力したモデルが右側に表示されます。
2. GLB内で物体の上に向かう軸を「モデルの上方向」で選ぶ。選択した軸を上に向けて、入力・分割・編集・結合の全ビューを表示します。方向を変えたら「パーツ構成を作成」から再実行します。
3. どのように編集したいかを文章で入力する。
4. 「パーツ構成を作成」を押す。
5. 物体名と、分割用の英語パーツ名・編集対象を確認する。UIのパーツ名にはInstruct-Particulateへ渡す`name`をそのまま使用します。
6. 「分割を実行」を押す。初回はGPUへの重みロードが必要です。
7. 分割結果の「表示パーツ」で全体・個別パーツを切り替える。
8. GLB・NPZ・対応表JSONをダウンロードする。
9. 「補正の順序」で「2辺共有補正 → CCS補正」または「CCS補正 → 2辺共有補正」を選ぶ。選んだ順にボタンが並び、前段は分割直後、後段は前段の結果をCPUで補正します。
10. 上から順に補正ボタンを押し、各段階を切り替えて比較する。順序を切り替えると、その順序の計算済み結果を復元します。前段を再実行すると選択中の順序の後段だけを無効にします。境界補正とCCSはGPU推論を呼び直しません。
11. 下段の「パーツ編集」で、自動設定された本体・接続方式・基準側を確認する。マグの取っ手なら`cup_body`を受け側、`handle`を延長側とする設定を確認できます。
12. なじませる接続だけなら、スライダー編集後に「なじませて一体化」を押す。境界の対応頂点を結合し、GLB・NPZ、形状検査を通過したSTLを保存できます。閉鎖して再結合する接続があれば、以下の①～④へ進みます。混在時は、なじませる接続を一致させたまま、付属部品の接続だけを延長します。古いプランでは「詳細な形状編集設定」で手動のなじませ対象・移動方法を選びます。
13. 「① 断面を閉じる」を押す。境界辺・水密性・面向き・保留理由を確認し、「閉鎖直後の形状を確認」で追加した蓋を表示する。
14. 「② 閉じたパーツを移動」のスライダーでパーツを自由に動かす。閉鎖した蓋も移動します。接続による移動の制限や巻き戻しはありません。
15. 「③ 接続部を延長する」を押して形状と各接続の延長量を確認し、その後「④ Booleanで統合」を押す。「Boolean結合 GLB」「Boolean結合 NPZ」「印刷用 STL」で保存できます。

### 閉鎖・移動・延長・Boolean結合を順に確認する

WindowsのUIに使用するPython環境で依存を更新し、Streamlitを再起動します。`manifold3d`と`rtree`が必要です。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8502
```

| 段階 | 操作 | 確認するもの |
|---|---|---|
| ① 閉鎖 | 「① 断面を閉じる」 | 蓋の形状・保留理由・残る境界・面の向き |
| ② 移動 | パーツ名の移動スライダー | 蓋付きパーツが移動する形状 |
| ③ 延長 | 「③ 接続部を延長する」 | 移動後の断面から受け側へ延びる形状と長さ |
| ④ 結合 | 「④ Booleanで統合」 | 内部の蓋・面を除去した色付きの一体形状 |

「蓋と食い込みの設定」で蓋の方式・非平面の試行・食い込み深さを指定します。初期値は中心からの放射状生成、非平面の試行オン、食い込み深さは断面幅の1%です。中空断面にはEarcutを選んでください。5%の延長上限は廃止し、実際の隙間に食い込み深さを足して長さを決めます。薄い受け側では深さを壁厚の10%以下に抑えます。

閉鎖結果は移動しても保持します。移動を変えると③・④の古い結果だけを無効にし、③を押し直して更新します。倍率・なじませ・蓋の方式など閉鎖形状が変わる設定では①から作り直します。食い込み深さの変更は③からです。ブラウザは移動する蓋を描画し、延長の探索や自動巻き戻しを行いません。

①の閉鎖が不完全でも、診断と作れた蓋は保持し、②の移動は続けられます。③で延長できない接続には理由を表示し、成功した接続の延長形状を確認できます。移動位置は戻しません。④は③で全接続を処理できた結果に対して実行します。

③は交差の有無で生成結果を破棄しません。延長後にパーツ内部の交差を診断し、延長前・延長後の件数と「パーツ内部の交差を赤く表示」で確認できます。赤色は表示専用で、GLB・NPZはパーツ色を保持し、交差診断も記録します。診断処理が失敗した場合も、生成済みの延長形状は保存できます。

④のBoolean結合では形状検査を継続します。自己交差した確認用モデルをそのまま印刷可能と扱うことはありません。延長方向に接続先が見つからない場合や、閉鎖した断面の対応を取得できない場合は、③でその理由を表示します。

各段階のGLB・NPZを個別に保存できます。「編集後 GLB」は蓋や延長を含む前の編集用表面です。印刷用STLでは「1座標単位を何mmにするか」を設定し、表示寸法を確認してください。STLに色は含みません。肉厚・強度・材料・プリンター条件の判定は含みません。

従来の断面閉鎖・開始頂点の比較・橋渡しによる再結合は、画面下の「従来の閉鎖・再結合を比較（詳細）」にまとめています。以下の三角形分割・開始頂点の操作説明は、その比較用機能についてです。新しい処理の詳細は[EDITING.md](EDITING.md#接続部を延長してbooleanで統合する)を参照してください。

移動スライダーは0付近で吸着し、初期位置へ戻しやすくしています。そのままドラッグを続けると吸着から抜けます。矢印キーでは0付近も一目盛りずつ微調整できます。

断面の「三角形の作り方」は初期値が「内点判定のみ（試行）」です。三角形候補の面積・凸角を判定せず、投影した内部に別の輪郭頂点がある場合だけ候補を不採用にします。「Earcut（従来）」へ切り替えて比較できます。中空断面は従来方式を使います。生成後の交差・面積0や極小の蓋は診断で確認してください。

「中心から放射状に生成」を選ぶと、断面ごとに中心Oを1頂点追加し、隣り合う境界頂点と三角形を作ります。「断面を閉じる」を押し、黄色の点O・追加頂点数・交差診断を確認してください。境界の3D位置とパーツ色を保ってGLB・NPZへ保存します。凹んだ輪郭での張り出しや重複は警告し、比較用に結果を保持します。中空断面は保留します。この方式では開始頂点の操作は無効です。

開始頂点を比較するには、対象の断面を選び「開始頂点を次へ」を押します。輪郭順に1頂点ずつ進めて蓋を自動で再生成し、何度でも巡回できます。「開始頂点を初期化」でその断面だけ元に戻せます。開始位置・最初の候補の番号と、プレビューの黄色の点Aを確認してください。他の断面の設定は保持します。

「Faceの重なりを表示」は初期状態でオンです。スライダーを離すと移動・倍率・なじませ後の交差を検査し、未編集時にはない交差ペアのFaceだけを赤く表示します。元から存在する交差ペアは除外しますが、同じFaceが別のFaceと新しく交差した場合は表示します。編集は止めないため、赤色を見てさらにパーツを移動できます。結合後も元Faceの対応情報で比較し、追加した接続面との交差も検査します。赤色は表示専用で、出力GLB/NPZのパーツ色は保持します。

判定の中心・縮尺・許容誤差は未編集モデルに固定し、別パーツの移動で静止面の判定条件が変わることを防ぎます。平行移動・一様な拡大縮小だけのパーツ内部は新規交差から除外します。パーツ間の交差、境界なじませ・断面固定移動による自己交差、結合で追加・変更された面の交差は検査します。

境界補正とCCSを順に使う前に、[追加ファイルの配置手順](../ip-object-name/BOUNDARY_POSTPROCESSING.md)でWSLのAPIを更新してください。旧版で自動境界補正された分割結果は、一度再分割が必要です。
スケーリングの定義、状態のリセット、表示とPythonの対応は[EDITING.md](EDITING.md)を参照してください。今回の編集機能追加にWSL側の更新は不要です。

結果のJSONをダウンロードできます。元モデルと処理結果はWSL側の`data/models/<model_id>`に保存されます。
上段の「入力モデル」は元のGLB、下段の「分割結果」は分割後の独立メッシュです。
要求文を変更すると前のパーツ表と分割表示を非表示にし、再実行時にLLMへ新しい要求を渡します。
同じモデル・向き・接続先なら登録と名前推定を再利用します。
分割結果はWSLに保存され、API経由でWindows側へ取得します。WindowsからWSLのファイルパスを直接開く必要はありません。
分割した面の保存形式と、後のPython編集への受け渡しは[SEGMENTATION.md](../ip-object-name/SEGMENTATION.md)を参照してください。
